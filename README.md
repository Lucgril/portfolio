# Luca Grillo | Senior Software Engineer - Personal Portfolio 🚀

> A clean, high-performance, and fully responsive personal portfolio built with React, TypeScript, and Vite. Designed to showcase enterprise-level software engineering skills, architectural solutions, and RPA expertise.

🔗 **[View Live Portfolio](https://lucgril.github.io/portfolio)**

## 🛠 Tech Stack

*   **Core:** React 18, TypeScript, Vite
*   **Styling:** Tailwind CSS (v3) - Custom Cyberpunk/Dark theme
*   **Internationalization (i18n):** `react-i18next` (English & Italian support)
*   **Icons:** Lucide React
*   **Deployment:** GitHub Pages (`gh-pages`)

## ✨ Key Features

*   **Multi-language Support:** Seamless switching between Italian and English using `i18next`.
*   **Dynamic Asset Delivery:** Automatically serves the correct localized CV (PDF) based on the currently selected language.
*   **Responsive Architecture:** Pixel-perfect alignment and reading experience across mobile, tablet, and desktop devices.
*   **Performance Optimized:** Built with Vite for lightning-fast HMR and optimized production builds.
